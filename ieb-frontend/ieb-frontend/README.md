# IEB Management System — Frontend

Enterprise admin UI for Institution of Engineers, Bangladesh (IEB).

Backend API: https://fanciful-torrone-561891.netlify.app/api

## Quick start

```bash
cd ieb-frontend
npm install
cp .env.example .env
npm run dev
```

Demo login: admin@ieb-demo.local / ChangeMe123!

## Deploy to Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Env: `VITE_API_BASE_URL=https://fanciful-torrone-561891.netlify.app/api`
